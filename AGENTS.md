# Working agreement

- The user must test and confirm a build before it is pushed or published.
- Do not run `git push`, push tags, or create GitHub Releases for a new build until the user confirms testing and authorizes publication.
- Requests to continue implementation do not authorize publication.
- Continue local edits, automated checks, and ZIP packaging without waiting for publication approval.
- Clearly label local test builds and report any missing real-browser verification.
